最后更新：2026-10-27Last updated: 2026-10-27

本站是 8 个个人作品站的导航总站，托管在 GitHub Pages 上。本页说明总站如何处理访问者可能产生的信息。

1. 本站主动收集的信息

总站目前没有接入访问统计、广告脚本或第三方分析服务，也没有设置自有 cookie。除下文说明的情形外，本站不会主动收集、存储或分享你的个人信息。

页面会在你的浏览器本地保存一项语言偏好（localStorage），用来记住你选择的中文或英文界面。这项数据只存在你的设备上，不会发送给本站或任何第三方。

2. 托管平台日志

本站由 GitHub Pages 托管。GitHub 可能按照其隐私声明记录访问日志（例如 IP 地址、浏览器类型、访问时间），用于安全与运维。这部分数据不在本站的控制范围内，详见 GitHub 隐私声明。

3. 反馈邮件

如果你通过邮件联系我们，我们会收到你的邮箱地址、邮件正文和附件。这些信息仅用于回复问题和改进作品，不会出售或主动提供给第三方。

4. 外部链接

总站链接到 8 个作品站以及其他外部网站。这些网站有自己的隐私政策，本站不对其内容或数据处理方式负责。

5. 广告与第三方 Cookie

本站目前不展示广告。未来若接入 Google AdSense 等第三方广告服务，Google 及其合作方可能使用 cookie 或类似技术，根据你此前访问本站和其他网站的情况展示广告。届时你可以通过 Google 广告设置 或 aboutads.info 管理个性化广告。广告上线前我们会更新本页并注明日期。

6. 未成年人

本站不是面向儿童的产品，也不会主动收集未成年人的个人信息。如果你是未成年人，请在监护人指导下使用本站。

7. 政策变更

如果数据处理方式发生变化，我们会更新本页并修改文末日期；涉及广告或统计的重大变化会在总站首页说明。

8. 联系方式

对隐私或数据有疑问，可发邮件至 898249759@qq.com（主）或 yangfan.070312@gmail.com。
