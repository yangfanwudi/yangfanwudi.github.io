规则 截面是怎么定出来的

一、什么是截面

  • 用一个平面去切立体，切口围成的闭合平面图形就是截面；实验台里荧光黄绿的填充与亮轮廓即截面。
  • 截面的每条边是平面与立体某个面的交线，所以边数 = 平面穿过的面数：正方体最多 6 个面，截面最多 6 条边。
  • 半透明的是立体本身，亮线是它的棱；截面永远画在实体之上，不会被挡住。

二、三点定面

  • 不共线、不重合的三个点确定唯一平面——这是截面的唯一依据，点 A/B/C 就是这三个点。
  • 三点共线或重合：定不出平面，状态行说明原因，不显示假数值。
  • 三点极接近共线：仍计算，但提示截平面不稳定（软警告）。
  • 截平面恰好与某个面重合：返回该面本身的边界（如正方体整面 = 正方形 1.000 / 4.000），属正确结果。

三、点与拖动

  • A/B/C 只能落在棱上：点击棱放点；满三点后再点新棱，循环替换最早的那个点。
  • 按住点只沿它所在的棱拖动；靠近端点 / 中点自动吸附（容差 0.01），可以精确落在顶点上。
  • 命中容差：鼠标 14px、触摸 26px（屏幕像素）；凑近缩放后点得更准。

四、数值怎么算

  • 形状 / 边数 / 面积 / 周长全部由交点坐标实时计算：面积用平面内三角化求和，周长用环边长求和，不是写死的数字。
  • 单位：长度 = 模型单位，面积 = 单位²。正方体棱长 1；长方体 4 × 3 × 2；正四棱锥底 2 × 2、高 2。
  • 显示保留三位小数；单元测试与独立手算公式交叉验证到 1e-9。

五、视角与手势

  • 位移 ≤ 8px 且 ≤ 600ms 的点击 / 轻点 = 放点；超过则视为拖动旋转，不放点。
  • 空白处单指 / 左键拖动 = 旋转；滚轮 / 双指捏合 = 缩放；双指不会误放点。
  • R 或"复位"：有激活预设时恢复该预设点位，否则清空点位；同时回标准视角。
  • 窗口宽高比变化（横竖屏 / 面板折叠）时相机沿当前视线自动拉远保证完整入镜，不改变你的旋转角度。

六、预设

  • 六个预设是典型截面（三角形 / 矩形 / 正六边形 / 正方形 / 五边形），坐标取规格精确值，一键放点并附教学说明。
  • 预设所属立体与当前不同时自动切换；手动改点后预设高亮失效，表示已偏离预设。
  • "复位"恢复当前预设点位；"清空点位"只清点、不动预设记录。
